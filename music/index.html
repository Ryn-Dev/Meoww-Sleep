Panduan Link & Fitur

1. Link YouTube (Audio Saja):

Mendukung link video YouTube biasa (watch?v=...), youtu.be, atau Shorts. Judul dan artis otomatis terisi dari internet, dan hanya suaranya yang dimainkan tanpa video!

2. Link Audio Langsung (.mp3, .ogg, .wav, .m4a):

Gunakan URL audio langsung dari internet (misal: hosting web, Discord CDN, stream radio internet, atau file publik).

3. Tekan & Geser Lagu (Ubah Urutan):

Gunakan ikon pegangan di sebelah nomor lagu pada playlist untuk menggeser posisi lagu ke atas atau ke bawah secara langsung!

4. Tampilan Controller (Pengaturan):

Klik tombol Pengaturan di navbar atau hero deck untuk memilih apakah tombol kontrol pemutar ditampilkan di Card Utama (Vinyl), Bar Melayang Bawah, atau keduanya.

5. Backup & Restore Playlist:

Gunakan tombol Export JSON untuk mengunduh cadangan playlist Anda ke file, dan Import JSON untuk membukanya kembali kapan pun.
